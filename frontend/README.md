# Frontend Workspace

Folder ini disiapkan untuk antarmuka pengguna (Web Interface / Dashboard AI Agent).

### Panduan Memulai:
Teman tim dapat menginisialisasi framework yang dipilih di folder ini (misalnya Next.js / Vite React / Vue / Tailwind):
```bash
# Contoh jika menggunakan Next.js:
npx create-next-app@latest .
# atau Vite:
npm create vite@latest .
```
